## 截图要求

1. **浏览器窗口最大化**（按 F11 全屏）
2. **清除浏览器缓存**（Ctrl+Shift+R 或 Cmd+Shift+R）
3. **截图工具推荐使用**：
   - macOS：Shift + Cmd + 4（区域截图）
   - 或浏览器开发者工具（F12）→ Cmd+Shift+P → "Capture full size screenshot"
4. **图片格式**：PNG（清晰度高）
5. **图片大小**：建议宽度 1920px，高度根据页面实际内容调整

## 截图步骤

### 1. 启动项目
```bash
# 终端 1：启动后端
cd /Users/lessy/Desktop/网络实习/server
node index.js

# 终端 2：启动前端
cd /Users/lessy/Desktop/网络实习

```

### 2. 访问系统
打开浏览器访问：`http://localhost:5173`

### 3. 按截图清单截取对应图片
将截图文件命名为 `home.png`、`dns.png` 等，放入本目录（`screenshots/`）。
